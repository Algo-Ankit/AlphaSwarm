# AlphaSwarm — dependency lock (pins for reproducible installs)
#
# WHY: requirements.txt uses open ">=" floors, so every CI run and Docker build
# used to resolve to whatever was newest on PyPI that day. One bad upstream
# release then broke the pipeline non-deterministically (this is exactly what
# failed CI on 2026-07-09). This file pins the full resolved dependency graph to
# a known-good set (verified: 121/121 tests pass) so installs are reproducible.
#
# USAGE: always installed as a constraints file, never on its own:
#   pip install -r requirements.txt -c constraints.txt
#
# HOW TO UPDATE (do this deliberately, not incidentally):
#   1. pip install -r requirements.txt        # in a clean venv, no -c
#   2. run the test suite (pytest) — must stay green
#   3. pip freeze | sort > constraints.txt    # then re-add this header
#

# so it is safe for the 3.12 runtime (Dockerfile) and the CI matrix.
